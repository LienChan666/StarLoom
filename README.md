# Starloom

Starloom 是一个面向 FFXIV 的 Dalamud 插件，主要用于处理收藏品提交、工票兑换，以及与制作循环衔接的部分自动化流程。

## 功能概览

- 在背包空位接近阈值时接管流程，执行收藏品提交与工票物品购买。
- 支持配置收藏品商店、购买目标、保留工票数量和返回点。
- 提供围绕工票商店的搜索、选择、已拥有数量展示和列表管理能力。

## 项目状态
